# Menetelmä ja luokittelu

## 1. Tarkastuksen yksikkö

Jokainen julkaisu saa pysyvän tunnisteen ja oman analyysikortin. Saman tutkimushankkeen useita artikkeleita ei yhdistetä huomaamatta yhdeksi lähteeksi: jokaisen artikkelin tutkimuskysymys, analyysi ja rahoitusilmoitus tarkistetaan erikseen.

## 2. Pakolliset tiedot

| Kenttä | Mitä kirjataan |
|---|---|
| Viite ja pysyvä tunniste | Tekijät, vuosi, nimi, lehti, DOI/PMID/PMCID |
| Vertaisarviointi | Varmistettu julkaisijan tai tietokannan tiedoista; epäselvä tapaus merkitään avoimeksi |
| Julkaisutyyppi | Koe, havainnoiva tutkimus, kysely, laboratoriotutkimus, tapaussarja, katsaus, systemaattinen katsaus tai muu |
| Toteuttaja | Kirjoittajat, tutkimusryhmä ja ilmoitetut organisaatiot |
| Aloitteentekijä/suunnittelija | Tekijäpanoslausuman tai protokollan perusteella |
| Tilaaja/toimeksiantaja | Vain nimenomaisesti ilmoitettu tilaussuhde; muuten ”ei ilmoitettu” |
| Rahoittaja | Kaikki tutkimus-, hanke-, henkilö- ja julkaisemisrahoitus |
| Luontoissuoritukset | Ruoka, näytteet, laitteet, analyysit, henkilöstö, ohjelmistot tai muu maksuton tuki |
| Rahoittajan rooli | Suunnittelu, aineiston keruu, analyysi, tulkinta, käsikirjoitus, julkaisupäätös ja aineiston hallinta |
| Eturistiriidat | Kirjoittajien oma ilmoitus sekä suoraan todennettavat työnantaja- ja omistussuhteet |
| Tutkimuksen tarkoitus | Artikkelin oma tavoite tai tutkimuskysymys, ei myöhempi markkinointiväite |
| Päätelmäraja | Mitä asetelma voi ja ei voi osoittaa |
| Todiste ja tarkistuspäivä | Linkki ensisijaiseen lähteeseen ja tarkistuspäivä |

## 3. Todistejärjestys

1. Koko vertaisarvioitu artikkeli ja sen korjaukset.
2. Julkaisijan lisäaineisto, tutkimusprotokolla ja rekisterimerkintä.
3. Rahoittajan tai tutkimusorganisaation virallinen hanke- tai apuraharekisteri.
4. Luotettava ulkopuolinen lähde, jos ensisijainen aineisto ei riitä.
5. Hakukoneen katkelmaa ei käytetä lopullisena todisteena, jos alkuperäinen asiakirja on saatavilla.

Pelkkä abstrakti riittää tarkoituksen alustavaan kirjaamiseen, mutta ei rahoituksen ja sidonnaisuuksien valmiiksi merkitsemiseen.

## 4. Rahoitusluokat

Rahoitus kuvataan sanallisesti. Yhtä numeroa tai ”luotettavuuspistettä” ei käytetä, koska rahoituslähde ja tutkimuksen menetelmällinen laatu ovat eri asioita.

- Julkinen tai yliopiston perusrahoitus
- Säätiö- tai yleishyödyllinen rahoitus
- Kaupallinen tutkimusrahoitus
- Kaupallinen luontoissuoritus
- Sekarahoitus
- Ei erityistä tutkimusapurahaa ilmoitettu
- Rahoitusta ei ilmoitettu
- Ei vielä varmennettu

## 5. Sidonnaisuusrakenteen kuvaus

Erityistä huomiota vaativat tilanteet kirjataan näkyvästi:

- rahoittajan työntekijä tai omistaja on kirjoittajana;
- rahoittaja on osallistunut asetelmaan, analyysiin tai käsikirjoitukseen;
- tutkimusruoka tai muu tutkittava tuote on saatu valmistajalta;
- aineisto on sponsorin omistuksessa tai sen käyttö edellyttää sponsorin lupaa;
- vertailuruokavaliot eroavat käsittelyn lisäksi olennaisesti ravintoainekoostumuksessa;
- rahoitus- tai eturistiriitalausuma puuttuu kokonaan.

Merkintä ei vielä ole näyttö vinoumasta. Se on tarkistettava rakenne, joka yhdistetään tutkimusasetelman ja raportoinnin arvioon.

## 6. Kielenkäyttö

- ”Ei ilmoitettu” tarkoittaa, ettei asiaa löytynyt tarkastetusta julkaisusta.
- ”Ei ollut” kirjoitetaan vain, jos artikkeli nimenomaisesti niin ilmoittaa.
- ”Rahoittaja” ei ole automaattisesti ”tilaaja”.
- ”Tutkijoiden suunnittelema” merkitään päätelmäksi vain, jos tekijäpanoslausuma tukee sitä.
- Yrityksen toimittamaa ruokaa ei nimetä tutkimusrahoitukseksi, jos artikkeli kuvaa sen vain luontoissuorituksena.
- Yhteys ei kumoa tulosta, eikä puuttuva yhteys todista tulosta oikeaksi.

## 7. Laadunvarmistus

Valmis analyysikortti edellyttää vähintään kahta tarkistusta: bibliografinen tunnistus sekä rahoitus-/sidonnaisuusosion tarkistus koko tekstistä. Epäselvät tiedot jäävät avoimeen työjonoon eikä niitä täytetä oletuksilla.
